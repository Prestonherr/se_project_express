# WTWR (What to Wear) — Backend

Backend for WTWR

**What this service does:**

- User registration & authentication (JWT)
- Persistent user profiles and avatar support
- CRUD for clothing items with like/unlike functionality
- Public items listing and protected item management
- Request validation, centralized error handling and request logging

**Technologies & Libraries**

- Node.js
- Express
- MongoDB
- Mongoose
- JSON Web Tokens (`jsonwebtoken`) for auth
- `bcryptjs` for password hashing
- `celebrate` / Joi for request validation
- `winston` + `express-winston` for logging
- `dotenv` for environment configuration

**Dev tooling**: Nodemon, ESLint, Prettier
